# Asset-Draw Coding Agent Rules

Read README.md, docs/REFERENCE_UX.md and the Asset-Draw AI Coding Agent Implementation Pack before major changes.

Work incrementally. Never silently invent legal decisions. Do not enable paid entry by default. Never add manual winner selection. Never trust frontend payment success. Use transactions and idempotency for critical workflows. Draw snapshots/results must be immutable and independently verifiable. Use Alembic for PostgreSQL migrations. Do not introduce microservices, blockchain, or AI/ML into the MVP.

Start by inspecting the repository, then implement one phase at a time and run tests after each phase.
