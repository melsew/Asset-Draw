# Release readiness prompt
Produce a checklist marked PASS / FAIL / BLOCKED BY DECISION covering: migrations from an empty DB, config, reproducible
build, tests, security scans, backup and restore, monitoring, TLS, RBAC, payment status, draw protocol and vectors, public
verification, audit chain, Amharic/English UI, runbooks, and every OPEN item in `docs/decisions.md`. Never turn BLOCKED BY
DECISION into an assumption.
